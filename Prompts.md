# Prompts Used

This file contains the prompts used to generate the server implementation.

- "Create a basic Express server listening on Port 5000"
- "Create 5 basic REST routes for a Blog (GET /posts, GET /posts/:id, POST /posts, PUT /posts/:id, DELETE /posts/:id)"
- "Add a mock database and full CRUD logic for the blog routes"
- "Add a custom middleware function that logs the HTTP Method, URL, and timestamp to the console for every incoming request"
- "Create a fake authentication route POST /login that returns a mock JSON Web Token (JWT) string"
